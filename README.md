# PizzaFly — Drone Pizza Delivery Concept

A responsive React + Vite frontend concept for a futuristic pizza delivery service using drone-delivery simulations.

## Features

- Premium dark/orange startup-style UI
- Responsive navigation and mobile menu
- Pizza menu with real image URLs
- Functional cart with quantity controls and totals
- Checkout modal with customer details and payment UI
- Simulated order confirmation and order ID
- Animated drone tracking simulation (frontend only)
- Delivery timeline, battery, ETA, distance and speed
- Login/create-account UI
- About + responsible drone technology section
- Responsive desktop/tablet/mobile layouts

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite (normally `http://localhost:5173`).

## Important

Drone tracking is a frontend simulation. It does not use real GPS, aviation systems, autonomous drone control, payments, or authentication. Real deployment would require appropriate safety, aviation, privacy, payment and regulatory systems.
